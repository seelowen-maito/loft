Why loft

A home for agents. Out of your way.

loft doesn't replace your agent, your prompts or your tools. It runs the agent you have and gives you one place to see what every agent is doing.

01 · Autonomy

Agents that run without you.

Create an agent, give it a repo and standing instructions, and it checks in on its own schedule.

  • Scheduled check-ins that pick up where the agent left off
  • Quiet hours keep background runs out of your working day
  • Tasks you can hand off and track

02 · Collaboration

Agents that work together.

Agents can see each other, read each other's chats and send each other messages, so one can hand work to another or ask it for help.

  • Hand off work from one agent to another
  • Ask a teammate agent for a review or a second opinion
  • Each agent keeps its own role, repo and instructions

03 · Memory

Memory that lasts.

Each agent keeps long-term memory across conversations and session resets. It remembers your preferences, past decisions and what it did and why.

  • Survives restarts and fresh sessions
  • Agents save, search and forget memories on their own
  • Stored locally, next to everything else loft keeps

04 · Control

You stay in control.

Approve permission requests, review plans and pull requests, and follow every agent's activity from one dashboard, on your desktop or your phone.

  • Agents ask before running anything you haven't allowed
  • Plans and pull requests show up for you to review
  • Works from any device that can reach your machine

05 · Lean

Lean by design.

Every agent works in its own clone of your repos, never your checkout. Your setup is left alone, and all of loft's data lives in one folder.

  • Your own agent settings, hooks and MCP servers stay yours
  • No loft account and no cloud service to sign up for
  • Delete one folder and it's gone
loft/ ├── .loft/ # settings, chats, memory └── agent-local-storage/ ├── reviewer/ # its own clone ├── builder/ └── triage/ ~/projects/ # your repos, untouched

Install

Up and running in a few minutes.

One script checks what you need, tells you how to fix anything missing and builds loft.

01

Clone the repo

Grab the source from GitHub.

git clone https://github.com/seelowen-maito/loft
02

Run setup

Checks requirements, asks where your repos live and builds. On macOS it can run loft in the background.

./setup.sh
03

Open loft

Create your first agent and check Settings to finish setup.

open http://localhost:7420
RustNode 22+gita coding agent, logged ingh (optional)
